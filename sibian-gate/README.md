# 思辨开关 / Sibian Switch

DSH 插件：每条指令动手之前，先拦一次，问三个逻辑问题。

## 现在能做什么

- 左侧栏新增「思辨开关」入口，位置在「上下文洞察」下面、「更多」上面。
- 点开是面板：开关、三个问题的预览、台账说明。
- 开启后，图标右上角出现小绿点。
- 开启期间，根会话的每条新指令在模型第一次动手前会被注入一段门禁提示：
  1. 先复述指令，指出目的、前提和成功标准；
  2. 用 `ask_user_question` 一次问三个问题（目的 / 依据 / 替代），每题先给出一个反驳；
  3. 得到回答后，把 5 行决策卡追加到当前工作区的 `思辨台账.md`，再执行。
- 回答「跳过 / 直接做 / 别问了」时，只记一行跳过，然后执行。
- 子代理不拦；关闭后立即失效；开关状态全局保存，重启后仍在。

## 怎么用

1. **首次安装后刷新一次页面**（客户端模块要重新加载）。
2. 左侧栏点「思辨开关」→ 打开开关 → 绿点出现。
3. 回到会话，发一条新指令。模型会先停下来问三个问题。
4. 答完（或说跳过），它会先写台账，再继续做。

> 测试时注意：开关一开，下一条消息就会触发门禁。想安静聊天就先关掉。

## 测试与验收

按四级测；前两级过了，就能日常用。

### P0 · 壳子可用

- 刷新后左侧栏出现「思辨开关」，点开面板正常。
- 开关能点；点了之后状态 pill 和图标右上角绿点同步变化。
- 关掉页面再打开，开关状态还在。

### P1 · 门禁真的拦（核心）

1. 打开开关。
2. 在**根会话**发一条新指令，例如「帮我把这段仿真跑一下」。
3. 预期：模型在调用其他工具之前，先调 `ask_user_question` 一次问三题
   （目的 / 依据 / 替代），每题带自己的反驳。
4. 答完（或说「跳过」）后，预期：工作区出现 `思辨台账.md`，里面有一张
   5 行决策卡，然后才开始做原任务。
5. 同一条指令只拦一次；模型进入工具循环后不应重复问。

### P2 · 边界

- 关掉开关再发指令：不再问，直接执行。
- 子代理 / 委派任务：不拦。
- 说「跳过 / 直接做 / 别问了」：只写一行跳过，然后执行。
- 重启 DSH：开关状态保留。

### 什么算“可用”

P0 + P1 全过 = 日常可用；P2 用来确认不会误伤。

已知限制：它是提示词门禁，不是硬拦截。模型仍可能忽略；忽略时应在台账里
留下跳过记录。若模型反复忽略，下一版再加工具层闸门。

## 设计边界

- 只做逻辑层：不判断地磁导航结论对不对，不替你查文献。
- 是提醒，不是硬拦截：模型仍可能忽略；忽略时它应把跳过记进台账。
- 全局开关：所有根会话生效；子代理除外。
- 台账由模型用自己的文件工具写，插件不读取、不上传。

## 改题库

三个问题写在 `index.js` 的 `gateText()` 里，改完在插件管理里重载插件或重启 DSH。
面板里的问题预览在 `client.js` 的 `GatePanel` 中，两边要一起改。

## 状态与卸载

- 状态文件：`~/.dsh/storages/sibian-gate/state.json`（`{"armed": true/false}`）。
- 安装方式是 `link:` 到本目录，**不要移动或删除这个文件夹**，否则插件失效。
- 卸载：在插件管理里停用 / 移除 `@local/dsh-sibian-gate`。

## 已验证 / 未验证

已验证：

- `node --test test/host.test.mjs test/client.test.mjs`：8 pass，0 fail。
- 运行中的插件行 `include:sibian-gate`，`fiberPhase: active`（Host 已加载）。
- 路由实测（带登录 cookie）：`POST /api/sibian-gate/state` 返回
  `{ok:true,value:{armed:false}}`；`/toggle` 能翻转开关并同步写
  `~/.dsh/storages/sibian-gate/state.json`。
- 客户端模块已进入启动清单，并由服务端以 200 返回：
  `plugins/??@local/dsh-sibian-gate/client.js&rev=...`。

未验证：

- 浏览器里的实际渲染（侧边栏入口、绿点、面板开关）仍需刷新后目视确认。
- 真实会话里的门禁触发与台账写入，需要开启后发一条新指令才能确认。
- 若刷新后左侧栏没有「思辨开关」，先看浏览器控制台是否有 `sibian-gate`
  相关报错；再确认页面地址仍是 `http://127.0.0.1:3080`。
